# 📊 TableGen Linux - Smart Bidirectional Markdown, Sheets & CSV Table Converter

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Linux%20(X11%20%26%20GNOME)-orange.svg)]()
[![Python](https://img.shields.io/badge/Python-3.8%2B-green.svg)]()

Convert tabular data back and forth between **Excel / Google Sheets, Markdown tables, CSV, HTML, and JSON** with a single global shortcut (`Alt + T`)!

---

## ✨ Features

- ⚡ **Instant Global Shortcut (`Alt + T`):** Copy any table data, press `Alt + T`, select target format, and watch it paste in-place.
- 🔄 **Bidirectional Conversions:**
  - 📊 Excel / Google Sheets ➔ Clean Markdown Table
  - 📑 Markdown Table ➔ Google Sheets / Excel TSV Format (paste directly into spreadsheet cells!)
  - 📄 CSV / TSV ➔ Markdown, HTML `<table>`, JSON Array of Objects
  - 📦 JSON Array ➔ Markdown Table
- 💻 **CLI Interface:** `table md`, `table sheets`, `table csv`, `table json`.

---

## 🛠️ Installation

```bash
git clone https://github.com/domz-1/tablegen.git
cd tablegen
make install
```
